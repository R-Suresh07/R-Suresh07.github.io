## Begin with the quantity that matters

A useful measurement starts with a precise question. The point is not to collect every available signal, but to identify the smallest observation that can distinguish two plausible explanations. This fixture essay tests the typography and media system without introducing migrated personal content.

For an event with predicted probability $p$ and outcome $y \in \{0, 1\}$, a simple squared loss is

$$
L(p, y) = (p - y)^2.
$$

The equation should remain readable in the prose column and scroll safely on a narrow screen. For more background, follow a [descriptive link to the writing index](/writing/), which also demonstrates link treatment and focus behavior.

The implementation can stay compact. Build-time rendering gives the page highlighted code without sending a client-side syntax highlighter:

```ts
type Observation = { predicted: number; observed: 0 | 1 };

export function squaredLoss(sample: Observation) {
  return (sample.predicted - sample.observed) ** 2;
}
```

> **Interpretation note.** A lower aggregate loss is useful only when the evaluation set represents the decisions the system will actually encounter. Treat a clean metric as evidence, not as a conclusion.

## Motion as evidence

This fixture supplies a poster but intentionally no migrated video asset; adding WebM and MP4 sources later will activate playback without changing article markup.
